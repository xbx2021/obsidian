子代理的价值就在这里：它去执行这些高噪声任务，然后只把**结论**带回主对话。

创建两个子代理。一个是**测试运行器**，负责执行测试，总结结果。另一个是**日志分析器**，用来分析日志，提取关键问题。

学习目标：

1. 理解“信噪比”框架，学会判断哪些任务适合委托给子代理。

2. 掌握子代理输出格式设计的方法论，而非只学一个固定模板。

这些框架和方法，会为我们在实操过程中明确：什么时候需要引入子代理，并形成一套原则性的设计思路。
