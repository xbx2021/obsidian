## 一、整体顶层接口（最上层）
Java 并发队列**全部基于 Java 集合框架标准接口**扩展，顶层结构如下：

```
Iterable
  ↑
Collection
  ↑
Queue  ←—————— 核心队列接口（java.util.Queue）
  ↑
BlockingQueue  ←—————— JUC 核心阻塞队列接口（java.util.concurrent）
  ↑
(所有 JUC 阻塞队列实现类)
```

**补充：双端队列独立分支**
```
Deque  ←—————— 双端队列接口（java.util.Deque）
  ↑
BlockingDeque  ←—————— JUC 阻塞双端队列接口
  ↑
LinkedBlockingDeque
```

## 三、JUC 队列类清单（Java 8 全部）
### 1. 阻塞队列（**最常用、核心**）
实现 `BlockingQueue`：
1. **ArrayBlockingQueue**
   数组实现、有界、公平/非公平
2. **LinkedBlockingQueue**
   链表实现、可选有界、高吞吐
3. **PriorityBlockingQueue**
   优先级队列、无界
4. **SynchronousQueue**
   容量为 0、直接传递、无存储
5. **DelayQueue**
   延时队列、无界、按过期时间出队
6. **TransferQueue**
   Java 7 新增、支持生产者等待消费者
   → Java 8 实现：**LinkedTransferQueue**

### 2. 阻塞双端队列
实现 `BlockingDeque`：
- **LinkedBlockingDeque**
  链表双端阻塞队列

## 四、关键接口方法（类图必备）
### BlockingQueue 核心阻塞方法
- `put(e)`：入队，满则阻塞
- `take()`：出队，空则阻塞
- `offer(e, timeout)`：超时入队
- `poll(timeout)`：超时出队

### BlockingDeque
- 双向都能 put/take

### 总结
1. **JUC 队列 = BlockingQueue 系列 + BlockingDeque 系列**
2. **6 个标准阻塞队列**：Array/Linked/Priority/Synchronous/Delay/Transfer
3. **1 个阻塞双端队列**：LinkedBlockingDeque
4. 全部基于 `Queue/Deque` 标准集合接口
